# 警察抓小偷（Lode Runner 重制版）

中华学习机 / Apple II 上那盘《警察抓小偷》（Lode Runner）的安卓重制版。
**你扮演小偷**，在砖砌的地下迷宫里偷光所有金子，然后爬上顶部闪光的梯子溜走；
**警察**会一路追你，碰到就被抓。

> 与同目录下的 `CopsAndRobbers/`（另一个警察抓小偷，追逐玩法）是两个完全独立的工程，包名不同，可同时安装。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 左下大方向键 | 左右走动；站在梯子上按上/下攀爬；挂在横杆上按下可松手掉下去 |
| 右下「◀ 挖左 / 挖右 ▶」 | 挖掉脚边斜下方的砖，形成一个会回填的坑 |
| 键盘 | 方向键或 WASD 移动，Z / X 挖洞（模拟器、电视可用） |

### 触屏控件为什么这么放

关卡画面居中，左右两侧留白专门放大号控件，手指不会碰到格子：

- **方向键**是一整块方形区域，按对角线切成四个互不重叠的梯形区（四个角也算数），
  任何落点只会对应一个方向；正中间的小方块是**死区**，按上去不响应，
  四臂交汇处因此不会误判。手指按下后可以滑动改方向，滑进死区时保持原方向。
- **挖左 / 挖右**两个圆键之间永远留一道缝（命中判定只比视觉半径大 10%，
  不像早期版本那样把判定圈放大到互相重叠）。
- 屏幕太窄、并排会导致挖键直径不足 48 dp 时，自动改成**上下排列**，反而能做得更大。

尺寸可以用 `python check_layout.py` 自检（会列出 9 种屏幕尺寸下方向键与挖键的 dp 值、键间间隙、
以及是否越界压到关卡）；`python preview_ui.py 1 2340 1080` 会按同样参数画出完整界面预览图。

规则细节：

- **不能跳**。只能走、爬梯、挂横杆、下落、挖洞 —— 和原版一致。
- **挖坑是双刃剑**：警察掉进去会被困住，坑回填时他还在里面就被**埋掉**（+150 分，从顶部重生）；
  但你自己掉进去也出不来，坑回填时你还在里面同样被埋。
- **挖穿地板**可以下一层，这是抄近路的核心手段（坑 3.6 秒回填，动作要快）。
- 收齐所有金子后，顶部的隐藏出口梯开始闪光，爬上去过关。
- 3 条命；每关开场（以及每次复活）警察会冻结 2.2 秒，给你反应时间。

## 关卡

`gen_levels.py` 程序生成 12 关（金子 10 → 22 块，警察 2 → 5 个），并且**逐关校验**：

1. 每块金子和出口梯在「走 / 爬梯 / 下落 / 挖穿地板」的真实规则下**可达**；
2. 警察与小偷起点的路径距离不低于阈值（第 1 关 ≥ 18）；
3. 若警察与小偷同层，必须存在一条**比警察更近**的上行梯子 —— 不会出现被堵死在死胡同里的情况；
4. 每层至少 3 条上行梯子，相邻两层梯子的横向位置强制错开，逼你绕路。

第 1 关刻意做得宽松：警察只出现在中上层，金子主要铺在下面两层。

改关卡只要改脚本重跑：`python gen_levels.py`（会覆盖 `Levels.kt`）。

## 画面

全部素材在运行时用 16×16 像素矩阵预渲染成 Bitmap，再按**整数倍**放大绘制 —— 是硬的像素块，不会被插值糊掉。

- 砖墙：三层错缝砖 + 砖缝 + 顶光 / 底影
- 钢块（挖不动）：斜面立体 + 四角铆钉
- 梯子：木色双立柱 + 横档；横杆画在格子顶部，小偷是挂在下面的
- 金块：菱形金锭 + 6 帧循环闪光
- 坑：7 级回填动画，土从底部往上长
- 小偷：黑面罩 + 黑白横条纹囚服；警察：藏蓝警服 + 黄帽徽 + 腰带
- 角色有 站立 / 8 帧跑 / 爬梯 / 下落 / 挂杆 / 挖掘 / 阵亡 共 7 种姿态
- 洞穴背景颗粒 + CRT 扫描线 + 屏幕边框

`preview.py` 可以在电脑上离线渲染关卡 PNG 预览：`python preview.py 1 3`（第 1 关，3 倍放大）。

## 目录

```
app/src/main/java/com/haoly/loderunner/
  GameConfig.kt   常量与调色板
  Levels.kt       关卡数据（gen_levels.py 生成）
  Game.kt         状态机 / 移动 / 警察 AI / 规则
  Sprites.kt      像素素材工厂（地形 + 角色）
  Renderer.kt     Canvas 绘制
  Input.kt        触屏控件：方形方向键 + 挖键（防误碰布局）
  GameView.kt     SurfaceView 游戏循环
  MainActivity.kt 入口
```

工程根目录的辅助脚本：

```
gen_levels.py        生成并校验 12 个关卡 -> Levels.kt
check_layout.py      自检 9 种屏幕尺寸下控件的 dp 尺寸、间隙与越界
preview.py           渲染关卡画面 PNG
preview_ui.py        渲染「关卡 + 控件」完整界面 PNG
preview_sprites.py   渲染像素素材放大图
```

## 构建

```bash
cd LodeRunner
export JAVA_HOME="D:/software/Java/jdk-17"     # 默认 JDK 25 编不了 AGP 8.x
export ANDROID_HOME="D:/software/android/Sdk"
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`
